🎯 Objetivo do Projeto

Desenvolver uma aplicação web utilizando HTML, CSS, JavaScript e Python com Flask, integrando front-end e back-end por meio de páginas, rotas e listagem de produtos.

🧩 Dificuldades Conhecidas
- Integração entre front-end e back-end.
- Criação e organização das rotas no Flask.
- Navegação entre diferentes páginas.
- Estruturação e exibição dos produtos.
- Organização dos arquivos HTML, CSS, JavaScript e Python.

🛠️ Etapas do Desenvolvimento
- Planejamento da estrutura da aplicação.
- Criação das páginas utilizando HTML.
- Desenvolvimento da estilização com CSS.
- Implementação das interações com JavaScript.
- Configuração do Flask e criação do servidor.
- Criação das rotas do back-end.
- Implementação da listagem de produtos.
- Integração entre front-end e back-end.
- Testes de navegação e funcionalidades.
- Organização e revisão do projeto.

🔧 Tecnologias e Serviços Utilizados
- HTML
- CSS
- JavaScript
- Python
- Flask

➕ Dependências
- Flask
